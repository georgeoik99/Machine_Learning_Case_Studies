# Ridge Regression Optimization — Pokémon Case Study

This project compares numerical optimization methods for Ridge Regression using 721 unique Pokémon species.

The target variable is `Attack`, predicted from `HP`, `Defense`, `Sp. Atk`, `Sp. Def` and `Speed`. The project covers Gradient Descent, Newton, SR1, AdaGrad, a simplified Trust-Region method, Projected Gradient Descent and SLSQP as a reference solver.

The optimizer structures originated from MSc coursework and were adapted, corrected and evaluated for this case study.
